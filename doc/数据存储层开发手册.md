# 芋道数据存储层开发手册

> 适用版本：yudao-server 全模块
> 基于 MyBatis-Plus + MyBatis-Plus-Join + Spring Data Redis

---

## 一、整体分层架构

调用链路：`Controller` → `Service` → `Mapper (MySQL)` / `RedisDAO (Redis)`

```
模块名/src/main/java/cn/iocoder/yudao/module/{模块}/
├── dal/
│   ├── dataobject/                     ← DO 数据对象（对应数据库表）
│   │   └── {业务域}/
│   │       └── XxxDO.java
│   ├── mysql/                          ← MySQL Mapper 接口
│   │   ├── {业务域}/
│   │   │   └── XxxMapper.java          ← 标准 CRUD，继承 BaseMapperX
│   │   └── statistics/                 ← 统计类（可选），不继承 BaseMapperX
│   └── redis/                          ← Redis DAO（可选）
│       ├── XxxRedisDAO.java
│       └── RedisKeyConstants.java
├── service/                            ← 业务服务层
│   └── {业务域}/
│       ├── XxxService.java             ← 接口
│       └── XxxServiceImpl.java         ← 实现
└── ...
```

**资源文件**：Mapper XML 放在 `src/main/resources/mapper/{业务域}/` 下，与 Mapper 接口包名对应。

**关键依赖**（pom.xml）：

```xml
<dependency>
    <groupId>cn.iocoder.boot</groupId>
    <artifactId>yudao-spring-boot-starter-mybatis</artifactId>
</dependency>
<dependency>
    <groupId>cn.iocoder.boot</groupId>
    <artifactId>yudao-spring-boot-starter-redis</artifactId>
</dependency>
```

`yudao-spring-boot-starter-mybatis` 内部集成了：
- `mybatis-plus-spring-boot4-starter` — MyBatis-Plus 核心
- `mybatis-plus-join-boot-starter` — 联表查询支持
- `dynamic-datasource-spring-boot4-starter` — 多数据源
- `druid-spring-boot-4-starter` — 连接池
- `mysql-connector-j` — MySQL 驱动（Oracle/PostgreSQL 等可选）

## 二、DO（Data Object）定义规范

### 2.1 继承 BaseDO

所有业务 DO 必须继承 `cn.iocoder.yudao.framework.mybatis.core.dataobject.BaseDO`，自动获得 5 个审计字段：

| 字段 | 类型 | 填充策略 | 说明 |
|------|------|----------|------|
| `createTime` | `LocalDateTime` | INSERT | 创建时间 |
| `updateTime` | `LocalDateTime` | INSERT_UPDATE | 更新时间 |
| `creator` | `String` | INSERT | 创建者 |
| `updater` | `String` | INSERT_UPDATE | 更新者 |
| `deleted` | `Boolean` | `@TableLogic` | 逻辑删除标记 |

这些字段由 `DefaultDBFieldHandler` 自动填充，代码中无需手动设置。`deleted` 由逻辑删除拦截器自动处理，所有查询自动附加 `deleted = 0` 条件（手动 SQL 除外，见 [第八节](#八手写-xml-sql-注意事项)）。

### 2.2 固定注解模板

每个 DO 类必须使用以下 7 个 Lombok 注解 + 2 个 MyBatis-Plus 注解：

```java
@TableName("crm_customer")                                   // 1. 数据库表名
@KeySequence("crm_customer_seq")                              // 2. 主键序列名（Oracle/PG 等需要，MySQL 可不写）
@Data                                                         // 3. getter/setter
@EqualsAndHashCode(callSuper = true)                          // 4. 包含父类字段
@ToString(callSuper = true)                                   // 5. 包含父类字段
@Builder                                                      // 6. Builder 模式
@NoArgsConstructor                                            // 7. 无参构造
@AllArgsConstructor                                           // 8. 全参构造
public class CrmCustomerDO extends BaseDO {

    @TableId                                                    // 9. 主键字段
    private Long id;

    private String name;
    // ...
}
```

### 2.3 金额字段约定

金额使用 `BigDecimal`，单位**元**（框架自动做分/元转换）：

```java
private BigDecimal totalPrice;  // 总金额，单位：元
private BigDecimal discountPercent;  // 折扣百分比
```

### 2.4 关联字段注释规范

外键字段和字典字段必须用 Javadoc 标注关联关系：

```java
/**
 * 负责人的用户编号
 *
 * 关联 AdminUserDO 的 id 字段
 */
private Long ownerUserId;

/**
 * 审批状态
 *
 * 枚举 {@link CrmAuditStatusEnum}
 */
private Integer auditStatus;

/**
 * 所属行业
 *
 * 对应字典 {@link DictTypeConstants#CRM_CUSTOMER_INDUSTRY}
 */
private Integer industryId;
```

## 三、Mapper 接口开发规范

### 3.1 模式一：标准 CRUD Mapper（继承 BaseMapperX）

适用于常规业务表的增删改查。

```java
@Mapper
public interface XxxMapper extends BaseMapperX<XxxDO> {

    // 查询逻辑使用 Java default 方法写在接口中

    default XxxDO selectByField(String value) {
        return selectOne(XxxDO::getFieldName, value);
    }

    default Long selectCountByStatus(Integer status) {
        return selectCount(XxxDO::getStatus, status);
    }

    default PageResult<XxxDO> selectPage(XxxPageReqVO pageReqVO) {
        MPJLambdaWrapperX<XxxDO> query = new MPJLambdaWrapperX<>();
        // 拼接数据权限条件（如有需要）
        query.selectAll(XxxDO.class)
                .likeIfPresent(XxxDO::getName, pageReqVO.getName())
                .eqIfPresent(XxxDO::getStatus, pageReqVO.getStatus())
                .orderByDesc(XxxDO::getId);
        return selectJoinPage(pageReqVO, XxxDO.class, query);
    }
}
```

### 3.2 BaseMapperX 核心方法速查

`BaseMapperX<T>` 继承 `MPJBaseMapper<T>` → `BaseMapper<T>`，提供丰富的便捷方法：

**查询方法：**

| 方法 | 说明 |
|------|------|
| `selectById(id)` | 按 ID 查询单条 |
| `selectByIds(ids)` | 按 ID 集合查询，空集合返回空列表 |
| `selectOne(字段, 值)` | 按单字段查询单条（支持 1~3 个字段） |
| `selectOne(wrapper)` | 自定义条件查询单条 |
| `selectFirstOne(字段, 值)` | 多结果时取第一条（避免 `TooManyResultsException`） |
| `selectLastOne(wrapper)` | 多结果时取最后一条 |
| `selectOneForUpdate(字段, 值)` | 悲观锁 `FOR UPDATE`（必须在事务中） |
| `selectList()` | 查询全部 |
| `selectList(字段, 值)` | 按单字段查询列表 |
| `selectList(字段, Collection)` | 按 IN 条件查询，空集合返回空列表 |
| `selectList(wrapper)` | 自定义条件查询列表 |
| `selectCount()` | 统计全部 |
| `selectCount(字段, 值)` | 按单字段统计 |
| `selectCount(wrapper)` | 自定义条件统计 |

**分页方法：**

| 方法 | 说明 |
|------|------|
| `selectPage(pageParam, wrapper)` | 标准分页 |
| `selectPage(sortablePageParam, wrapper)` | 带排序的分页 |
| `selectJoinPage(pageParam, DTO.class, wrapper)` | 联表分页，结果映射为 DTO |

**写入方法：**

| 方法 | 说明 |
|------|------|
| `insert(entity)` | 单条插入 |
| `insertBatch(collection)` | 批量插入 |
| `insertBatch(collection, batchSize)` | 指定批量大小的插入 |
| `updateById(entity)` | 按 ID 更新 |
| `updateBatch(collection)` | 批量按 ID 更新 |
| `deleteById(id)` | 逻辑删除 |
| `delete(字段, 值)` | 按字段逻辑删除 |
| `deleteBatch(字段, Collection)` | 按 IN 条件批量逻辑删除 |

### 3.3 查询条件包装器

**单表查询 — `LambdaQueryWrapperX<T>`**：

```java
new LambdaQueryWrapperX<XxxDO>()
    .eqIfPresent(XxxDO::getStatus, pageReqVO.getStatus())       // 有值才拼接 =
    .likeIfPresent(XxxDO::getName, pageReqVO.getName())         // 有值才拼接 LIKE
    .inIfPresent(XxxDO::getId, ids)                             // 有值才拼接 IN
    .betweenIfPresent(XxxDO::getCreateTime, times)              // 有值才拼接 BETWEEN
    .orderByDesc(XxxDO::getId);
```

**联表查询 — `MPJLambdaWrapperX<T>`**：

```java
MPJLambdaWrapperX<XxxDO> query = new MPJLambdaWrapperX<>();
query.selectAll(XxxDO.class)
     .leftJoin(YyyDO.class, YyyDO::getId, XxxDO::getYyyId)     // 左连接
     .eqIfPresent(XxxDO::getName, pageReqVO.getName())
     .orderByDesc(XxxDO::getId);
return selectJoinPage(pageReqVO, XxxDO.class, query);
```

**更新条件 — `LambdaUpdateWrapper<T>`**（MyBatis-Plus 原生）：

```java
update(new LambdaUpdateWrapper<XxxDO>()
    .eq(XxxDO::getId, id)
    .set(XxxDO::getStatus, newStatus));
```

### 3.4 `xxxIfPresent()` 方法规则

| 方法 | 条件判断 |
|------|----------|
| `eqIfPresent` | `ObjectUtil.isNotEmpty(val)` 为 true 时拼接 |
| `neIfPresent` | `ObjectUtil.isNotEmpty(val)` 为 true 时拼接 |
| `likeIfPresent` | `StringUtils.hasText(val)` 为 true 时拼接 |
| `inIfPresent` | 集合非空且所有元素非空时拼接 |
| `gtIfPresent` / `geIfPresent` | `val != null` 时拼接 |
| `ltIfPresent` / `leIfPresent` | `val != null` 时拼接 |
| `betweenIfPresent` | 两个值都不为 null 时 `BETWEEN`；仅一个时 `>=` 或 `<=`；都没有时跳过 |

### 3.5 模式二：统计类 Mapper（不继承 BaseMapperX，使用 XML）

适用于复杂统计 SQL，只定义方法签名 + `@Mapper`，SQL 写在 XML 中。

```java
@Mapper
public interface XxxStatisticsMapper {

    List<XxxSummaryByDateRespVO> selectSummaryGroupByDate(XxxStatisticsReqVO reqVO);

    List<XxxSummaryByUserRespVO> selectSummaryGroupByUser(XxxStatisticsReqVO reqVO);
}
```

### 3.6 模式三：混合 Mapper（继承 BaseMapperX + 有 XML 方法）

```java
@Mapper
public interface XxxMapper extends BaseMapperX<XxxDO> {

    // Java default — 常规 CRUD
    default PageResult<XxxDO> selectPage(...) { ... }

    // XML — 复杂统计
    List<XxxSummaryRespVO> selectStatisticsGroupByDate(XxxStatisticsReqVO reqVO);
}
```

## 四、Mapper XML 规范

### 4.1 文件位置

`src/main/resources/mapper/{业务域}/{Mapper类名}.xml`

### 4.2 标准模板

```xml
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE mapper PUBLIC "-//mybatis.org//DTD Mapper 3.0//EN"
        "http://mybatis.org/dtd/mybatis-3-mapper.dtd">
<mapper namespace="cn.iocoder.yudao.module.{模块}.dal.mysql.{业务域}.XxxMapper">

    <select id="selectSummaryGroupByDate"
            resultType="cn.iocoder.yudao.module.{模块}.controller.admin.{业务域}.vo.XxxSummaryByDateRespVO">
        SELECT DATE_FORMAT(create_time, '%Y-%m-%d') AS time,
               COUNT(*) AS count
          FROM {table_name}
         WHERE deleted = 0
           AND owner_user_id IN
                <foreach collection="userIds" item="userId" open="(" close=")" separator=",">
                    #{userId}
                </foreach>
           AND create_time BETWEEN #{times[0],javaType=java.time.LocalDateTime}
                               AND #{times[1],javaType=java.time.LocalDateTime}
         GROUP BY time
    </select>

</mapper>
```

### 4.3 引用 Java 枚举值

```xml
<!-- 在 XML 中直接引用 Java 枚举常量 -->
AND audit_status = ${@cn.iocoder.yudao.module.{模块}.enums.AuditStatusEnum@APPROVE.status}
```

### 4.4 指定参数 javaType

当参数是 `LocalDateTime` 等非基本类型时，手动指定 `javaType`：

```xml
AND create_time BETWEEN #{times[0],javaType=java.time.LocalDateTime}
                    AND #{times[1],javaType=java.time.LocalDateTime}
```

## 五、Service 层数据访问模式

### 5.1 依赖注入

```java
@Service
@Validated
public class XxxServiceImpl implements XxxService {

    @Resource
    private XxxMapper xxxMapper;              // Mapper 注入

    @Resource @Lazy                            // 循环依赖用 @Lazy
    private YyyService yyyService;

    @Resource
    private ZzzApi zzzApi;                    // 跨模块 API 调用
}
```

### 5.2 标准增删改查

```java
// 查询
XxxDO entity = xxxMapper.selectById(id);
if (entity == null) {
    throw exception(XXX_NOT_EXISTS);
}

// 插入
XxxDO entity = BeanUtils.toBean(createReqVO, XxxDO.class);
entity.setOwnerUserId(userId);
xxxMapper.insert(entity);

// 更新（方式一：全量）
XxxDO updateObj = BeanUtils.toBean(updateReqVO, XxxDO.class);
xxxMapper.updateById(updateObj);

// 更新（方式二：只更新指定字段）
xxxMapper.updateById(new XxxDO().setId(id).setStatus(newStatus));

// 更新（方式三：LambdaUpdateWrapper）
xxxMapper.update(new LambdaUpdateWrapper<XxxDO>()
    .eq(XxxDO::getId, id)
    .set(XxxDO::getOwnerUserId, newOwnerUserId));

// 删除（逻辑删除）
xxxMapper.deleteById(id);

// 分页查询
PageResult<XxxDO> pageResult = xxxMapper.selectPage(pageReqVO, userId);

// 批量更新
xxxMapper.updateBatch(updateList);  // 按 ID 批量更新
```

### 5.3 对象转换工具

使用 `BeanUtils.toBean()` 进行对象转换：

```java
// 基础转换
XxxDO entity = BeanUtils.toBean(sourceVO, XxxDO.class);

// 带字段覆盖的转换
XxxDO entity = BeanUtils.toBean(sourceVO, XxxDO.class,
    item -> item.setOwnerTime(LocalDateTime.now()));
```

### 5.4 事务控制

```java
@Override
@Transactional(rollbackFor = Exception.class)
public Long createXxx(XxxSaveReqVO createReqVO, Long userId) {
    // 1. 插入主表
    xxxMapper.insert(entity);

    // 2. 插入关联数据
    relatedMapper.insertBatch(relatedList);

    // 如果任一操作抛出异常，全部回滚
    return entity.getId();
}
```

### 5.5 AOP 自调用解决方案

在 `@Transactional` 方法中调用本类的另一个 `@Transactional` 方法时，需要通过代理：

```java
private XxxServiceImpl getSelf() {
    return SpringUtil.getBean(getClass());
}

// 调用时
getSelf().innerTransactionalMethod(param);
```

## 六、Redis 数据访问

### 6.1 RedisKeyConstants

采用统一 Key 管理，放在 `dal/redis/RedisKeyConstants.java`：

```java
public interface RedisKeyConstants {

    // Key 格式：模块:功能:子功能
    String NO = "crm:seq_no:";
    String CACHE = "infra:cache:";
    // ...
}
```

### 6.2 RedisDAO

放在 `dal/redis/{功能}/` 下，标注 `@Repository`：

```java
@Repository
public class XxxNoRedisDAO {

    @Resource
    private StringRedisTemplate stringRedisTemplate;

    public String generate(String prefix) {
        String noPrefix = prefix + DateUtil.format(LocalDateTime.now(), DatePattern.PURE_DATE_PATTERN);
        String key = RedisKeyConstants.NO + noPrefix;
        Long no = stringRedisTemplate.opsForValue().increment(key);
        stringRedisTemplate.expire(key, Duration.ofDays(1L));
        return noPrefix + String.format("%06d", no);
    }
}
```

### 6.3 Redis 缓存策略

- 查询时先查 Redis，未命中则查 DB 并回写缓存
- 更新数据库后删除/更新对应缓存
- 设置合理的过期时间，避免缓存雪崩

## 七、枚举与错误码规范

### 7.1 业务枚举

实现框架接口 `ArrayValuable<T>`，提供 `getNameByType()` 静态方法：

```java
@RequiredArgsConstructor
@Getter
public enum StatusEnum implements ArrayValuable<Integer> {

    DRAFT(0, "草稿"),
    SUBMITTED(1, "已提交"),
    APPROVED(2, "已通过");

    public static final Integer[] ARRAYS = Arrays.stream(values())
            .map(StatusEnum::getStatus).toArray(Integer[]::new);

    private final Integer status;
    private final String name;

    public static String getNameByStatus(Integer status) {
        StatusEnum e = CollUtil.findOne(CollUtil.newArrayList(values()),
                item -> ObjUtil.equal(item.status, status));
        return e == null ? null : e.getName();
    }

    @Override
    public Integer[] array() { return ARRAYS; }
}
```

### 7.2 错误码

使用 `ErrorCode` 常量，放在 `enums/ErrorCodeConstants.java`（interface）：

```java
public interface ErrorCodeConstants {

    // 模块名 1-xxx-xxx-xxx，按模块分段分配
    ErrorCode XXX_NOT_EXISTS = new ErrorCode(1_001_001_000, "xxx不存在");
    ErrorCode XXX_NAME_DUPLICATE = new ErrorCode(1_001_001_001, "xxx名称已存在");
}
```

使用方式：

```java
import static cn.iocoder.yudao.module.xxx.enums.ErrorCodeConstants.*;
import static cn.iocoder.yudao.framework.common.exception.util.ServiceExceptionUtil.exception;

// 抛出带参数的异常
throw exception(XXX_NOT_EXISTS);

// 抛出带模板参数的异常
throw exception(XXX_NAME_DUPLICATE, entity.getName());
```

## 八、手写 XML SQL 注意事项

在 XML 中手写 SQL 时，由于绕过了 MyBatis-Plus 的拦截器，必须手动处理以下事项：

### 8.1 逻辑删除

**所有查询必须加 `WHERE deleted = 0`**，框架不会自动添加：

```sql
SELECT * FROM xxx_table
 WHERE deleted = 0
   AND status = #{status}
```

联表查询时多张表都需要：

```sql
SELECT a.id, b.name
  FROM table_a a
  LEFT JOIN table_b b ON a.id = b.a_id
 WHERE a.deleted = 0
   AND b.deleted = 0
```

### 8.2 多租户

如果启用了多租户，需要手动添加租户过滤条件（框架不会自动注入到 XML SQL 中）。

### 8.3 参数类型指定

`LocalDateTime` 等需要显式指定 `javaType`：

```xml
#{times[0],javaType=java.time.LocalDateTime}
```

### 9.1 新建数据实体

1. **创建 DO**：在 `dal/dataobject/{业务域}/XxxDO.java`，继承 `BaseDO`，遵循 [第二节注解模板](#22-固定注解模板)

5. **创建 RedisDAO**（如需要）：在 `dal/redis/{功能}/XxxRedisDAO.java`
6. **添加错误码**：在 `enums/ErrorCodeConstants.java`

## 十、关键约定速查

| 项目 | 约定 |
|------|------|
| **DO 基类** | 必须继承 `BaseDO` |
| **DO 注解** | 7 个 Lombok（`@Data` `@EqualsAndHashCode` `@ToString` `@Builder` `@NoArgsConstructor` `@AllArgsConstructor`） + `@TableName` + `@KeySequence` + `@TableId` |
| **主键** | `Long id` + `@TableId`，Oracle/PG 等加 `@KeySequence("表名_seq")` |
| **金额** | `BigDecimal`，单位**元**（数据库存分由框架自动转换） |
| **Mapper 基类** | 继承 `BaseMapperX<DO>` |
| **单表查询** | `LambdaQueryWrapperX<T>` |
| **联表查询** | `MPJLambdaWrapperX<T>` + `selectJoinPage()` |
| **条件拼接** | 优先用 `xxxIfPresent()` 方法 |
| **XML SQL** | 必须加 `WHERE deleted = 0` |
| **枚举引用 XML** | `${@完整类名@枚举值.字段}` |
| **事务** | `@Transactional(rollbackFor = Exception.class)` |
| **对象转换** | `BeanUtils.toBean()` |
